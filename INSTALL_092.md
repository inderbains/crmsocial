## Existing emails and resends
An existing registered email is rejected unless Auth app_metadata has the exact invitation ID created by this version. This includes old unlinked Auth accounts created by earlier invitation versions: do not automatically convert or delete them. Use a new email for testing or ask platform support to review stale accounts. A resend to the exact pending profile can reuse the reserved identity. Old invitation links are not supported. The previous inline workspace acceptance RPC is no longer executable by ordinary users; use the email activation flow instead.
