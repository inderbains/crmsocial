# RealVolt Fix 086 — Admin navigation and sign-out
Requires Fix 085. Only changes platform administration. The one-hour server verification window remains unchanged; refresh or Back/Forward in the same tab restores the dashboard only if the server confirms access. Explicit sign-out invalidates the email verification for the current session, signs out that Supabase session and clears tab storage. Browser back/forward cache is hidden on pagehide and reloaded on persisted pageshow. New tab behavior can depend on browser session-storage cloning; it is not guaranteed to be a distinct session. No private workspace session is read or cleared.

1. Back up the existing page and database; test on staging. Run the **contents** of `supabase/086_platform_admin_signout.sql` in Supabase SQL Editor (not the filename).
2. Replace only `app/admin/page.tsx` in GitHub. Keep existing CSS and Fix 085 Edge Function. Build and deploy normally.
3. Open `/admin/`, sign in and verify the email code once. Refresh; navigate away and back. Within the existing one-hour verification window, it should return to the dashboard. Sign out, then press Back and Forward: it must show login, never the old dashboard. Try again after verification expires. Test a non-owner account and a revoked session; both must be denied. Check that the normal agent workspace login is unaffected. Simulate offline sign-out: local session is cleared; a warning is shown if server revocation cannot be confirmed. Test in actual browsers, including back-forward cache.

Existing memory-only sessions from Fix 085 cannot be recovered; sign in once after installation. No live database, browser integration or full Next.js build was performed. For rollback restore the 085 page; the added sign-out RPC is harmless and can remain.
