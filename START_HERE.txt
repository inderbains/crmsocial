HOW TO UPLOAD
-------------
1. Back up your current GitHub repository or make a branch first.
2. Unzip this package ON YOUR COMPUTER.
3. In your GitHub repository, navigate to each matching folder and
   upload the corresponding file, preserving the exact path.
4. DO NOT upload files into the GitHub root. DO NOT upload the ZIP itself.
5. Do NOT remove your app, components, or lib directories.
6. Commit changes to main. Redeploy on Hostinger.
7. Open / and test public homepage.
8. Open /workspace directly (signed out) and test login.
9. Log in via homepage and confirm /workspace shows your existing CRM
   dashboard and that CRM, Transactions, Open Houses and SignVolt still work.
10. Click Agent Website from the dashboard and verify /agent-site-studio.

WHAT HAS NOT BEEN CHANGED
-------------------------
No database migrations. No changes to CRM contacts, open house records,
e-signatures, transactions, agent website database, domain, or inquiry API.

SIGN-IN CONFIGURATION
---------------------
Existing browser-side Supabase credentials must still be set:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Check Supabase Auth > URL Configuration includes:
https://YOUR-DOMAIN/workspace  (redirect allowlist for signup/reset)

If RealVolt already has a password recovery flow, it is preserved in
the existing dashboard component under /workspace.

SECURITY
--------
Do not put your Supabase service-role/secret key in GitHub or in any
NEXT_PUBLIC_ variable. This page uses only the public Supabase client.
Your existing server/API role access policies are not modified by this patch.
They must be audited separately before selling paid subscriptions.

WARNING FOR EXISTING WEBSITE OWNERS
-----------------------------------
AgentSiteStudio currently has a link 'Back to RealVolt' pointing to /.
Since / is now the PUBLIC homepage, use the 'Open dashboard' link in
that page (when signed in), or go directly to /workspace. You may later
update the Studio's back-link to /workspace for convenience.
