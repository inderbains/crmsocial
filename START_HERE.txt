RealVolt v1.6.0 — Professional Multi-Page Agent Websites
========================================================

Purpose: upgrade ONLY the public Agent Website pages, website Studio preview,
and approved custom-domain rewrites. No CRM, Open Houses, SignVolt, main
homepage, workspace menu, or Supabase schema files are included.

IMPORTANT: This patch is based on the crmsocial-main (1).zip uploaded earlier.
If you have modified the website files since that ZIP, review the changes before
replacing them. Do NOT upload the whole archive to GitHub as a ZIP.

Installation using GitHub:
 1. Download + EXTRACT this zip locally.
 2. For each file in this package, open the corresponding folder in GitHub.
 3. Replace matching files IN THEIR SAME FOLDERS. For new pages, create the
    nested folders exactly as listed below. Do not put page.tsx at repo root.
 4. Commit to the main branch and deploy with npm run build on Hostinger.
 5. Check the deployment log for routes /site/[slug]/[page] and
    /site-domain/[hostname]/[page].

Migrations 024 and 025 must already be applied for the earlier Agent Website

Limitations:
 - Listings page intentionally does NOT invent listings. Live DDF/MLS listing
   search requires a separate approved feed integration.
 - Contact form uses a mailto: link to prepare an email in the VISITOR'S email
   app; nothing is submitted to the CRM or sent automatically. A server-side
   lead capture endpoint with abuse protection and brokerage tenancy is a
   separate integration.
 - Custom domains only work once HTTPS, DNS, approved host mapping and
   existing application environment flags are correctly configured.
 - The built-in architectural vector is a decorative fallback. Agents should
   upload an authorized property/lifestyle photo via their Hero Photo URL.
 - Always keep public profile and brokerage information factually accurate.
