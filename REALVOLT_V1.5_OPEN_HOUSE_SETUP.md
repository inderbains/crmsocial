# RealVolt v1.5 — Open House QR Check-In

**This is an additive PATCH for the existing RealVolt v1.4 project, not a replacement application.**

## What this adds

- **Agent Workspace → Open Houses:** create an open house with property address, event start/end, agent and brokerage contact details.
- Upload a **public marketing MLS information PDF** (10 MB maximum) and optional property poster photo (5 MB maximum); optionally prefill the listing details from an existing RealVolt property page.
- Publish an open house and generate a scannable QR code for `https://YOUR-DOMAIN/open-house/?id=EVENT_UUID`.
- Print a branded property-photo poster with the QR code and the open-house date/time (`Print / Save PDF` from the browser).
- A mobile-friendly visitor check-in page requires full name, email, and phone before revealing the marketing-sheet link.
- Every unique registration creates/matches an **agent-owned CRM Contact**, adds `Open House` to tags, logs the property/event/source in CRM Notes, and creates a high-priority CRM follow-up task. The Open Houses screen lists leads with their source and document unlock counts.
- Optional, separate future-marketing consent. **No welcome email is sent.**
- QR generation is bundled locally; it does not use an external QR generation website.

## Install — GitHub

1. Back up your current `crmsocial` branch before changing any existing files.
2. Download the ZIP and **extract it**. **Do not upload the ZIP itself as source code.**
3. Upload the extracted files to matching paths in the existing GitHub repository. There are fewer than 100 files. Do not delete unrelated existing RealVolt files.
4. In **Supabase → SQL Editor**, run `supabase/021_open_house_qr_checkin.sql` once **after** the existing `002_workspace_properties.sql` and `003_crm.sql` migrations. The migration creates two tables, owner-only RLS, public check-in RPCs and the `realvolt-openhouse-public` Storage bucket.
5. Commit GitHub changes. Wait for Hostinger's build to succeed and deploy.
6. Log in to RealVolt and open **My Workspace → Open Houses**. Create a draft, attach your PDF marketing sheet and a property photo, then choose **Published**.
7. Choose **QR poster → Test visitor page** from a phone (or incognito/private window). Submit the form and open the MLS sheet. Back in your agent dashboard, confirm the registration and check **CRM → All Contacts**, **Notes** and **Follow-ups**.
8. Print the poster using the **Print / Save PDF** button. Confirm the QR scans from the printed page before using it at a real open house.

## Security & privacy notes

- **IMPORTANT: Supabase bucket is public by design.** A visitor must register through the RealVolt page to be shown the file link, but an MLS marketing PDF link can be copied or forwarded. **This is NOT secure storage for private information.** Never upload agreements, contracts, title documents, seller disclosures, Form B, financial data or any confidential material. Use it only for material you are permitted to distribute publicly.
- Visitor names, emails and phone numbers live in RLS-protected CRM/check-in tables, not in public storage. Only the agent owner sees their check-in list.
- The poster only shows permitted public listing and agent information, and the public event RPC does not reveal document paths or visitor data.
- This first release includes a honeypot and duplicate-email handling, but a production SaaS with open anonymous registration **should add edge rate limiting/CAPTCHA and monitoring** before broad public launch.
- Optional future marketing consent is separate from mandatory open-house contact registration. No messages are automatically sent.
- In v1.5, closing an event stops new check-ins; existing visitors who already received the publicly shareable document link can keep opening it. Cleanup of superseded photo/PDF objects is a future maintenance task.
